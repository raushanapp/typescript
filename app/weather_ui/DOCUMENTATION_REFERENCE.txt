🏗️ ARCHITECTURE

User Input
  ↓
Validation (Zod)
  ├─ Location API Call (Geocode)
  │   └─ Get coordinates
  ├─ Weather API Call (Open-Meteo)
  │   └─ Get weather data
  ├─ Data Transform
  │   └─ Map to UI objects
  ├─ Render Template (Nunjucks)
  │   └─ Generate HTML
  └─ Serve Response
      └─ Browser displays result
